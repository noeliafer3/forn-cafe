# Forn Café 1933 | Web de panadería y cafetería

Web de una sola página (scroll) para una panadería-cafetería ficticia, hecha con HTML, CSS y JavaScript sin frameworks ni build. Diseño propio en Canva

**Demo:** https://noeliafer3.github.io/forn-cafe

## Funcionalidades
- Hero con vídeo de fondo (con imagen de carga y pausa si el usuario prefiere menos movimiento)
- Ventana de productos con `<dialog>`: se abre al pulsar Horno, Pastelería o Café, se cierra con la X, `Esc` o pulsando fuera. Los productos se generan con JavaScript desde un único objeto de datos
- Menú fijo que se vuelve sólido al hacer scroll, con el enlace de la sección activa resaltado
- Menú desplegable en móvil
- Formulario de contacto con validación en el cliente (web de ejemplo, no envía datos)
- Carta en PDF que se abre en una pestaña nueva
- Animaciones de aparición al hacer scroll
- Responsive (móvil, tablet y escritorio) y accesible: HTML semántico, navegación con teclado, enlace para saltar al contenido y soporte de `prefers-reduced-motion`
